# Agent Note: Permission setup appearance

Status: implemented

## Problem

权限窗口的大标题、红色声明和重复卡片让必要设置显得沉重，且与设置页的中性灰分组不一致。用户需要清楚区分必需权限和可选权限，并理解哪些授权尚未完成。

## Decision

权限窗口采用小图标、左对齐介绍和一个包含两行权限的分组，复用[设置页外观](2026-11-04-macos-settings-appearance.md)的 `iceFormStyle.settings` 与[设置背景配色](2026-11-05-settings-surface-colors.md)，不另建权限专属调色板。状态使用文字和勾号同时表达，底部仅突出“开始使用”；辅助功能未开启时仍禁用该按钮，屏幕录制仍为可选。权限用途和可选权限的限制始终可见，替代红色隐私承诺和黄色继续按钮。

权限行直接观察现有 Permission 对象，复用其检查和请求机制。行内记录本次是否发起请求，仅在随后授权成功时返回权限窗口；离开视图后清除请求标记，不创建脱离视图生命周期的等待任务。辅助功能请求可能先显示系统提示，因此按钮使用“设置权限…”，屏幕录制继续使用“打开设置…”。

旧窗口的逐条用途说明、专用本地化文案及无人调用的 `waitForPermission` 等待接口随替换移除。权限模型仅保留当前窗口和高级设置页消费的检查、请求与状态；高级设置页仍使用的“授予权限”和“已授权”文案继续保留。

窗口恢复原生标题栏和安全区域，保持原有禁止关闭、最小化的策略，退出由“退出 Ice”明确执行。使用现有应用图标，不采用效果图中的替代图标。

## Alternatives considered

- 独立使用白卡片和冷蓝背景：与设置页不统一，深色和增强对比度也会出现平行样式维护。
- 保留两个大卡片，只缩小字号：重复标题、说明和边框仍然压低信息密度。
- 点击一次就创建一个等待授权的任务：重复点击会叠加等待，且继续使用后不应由迟到任务重新打开窗口。

## Consequences

中英文共享布局，说明文字可换行，颜色跟随系统外观。权限管理器、系统授权条件和初始化流程保持原有契约；本变更仅调整权限展示和窗口内授权反馈的生命周期。真实系统授权仍由用户操作，界面验证不能替代 macOS 权限往返测试。
