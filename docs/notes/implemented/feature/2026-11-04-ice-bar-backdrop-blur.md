# Agent Note: Ice Bar backdrop blur

Status: implemented

## Problem

Ice Bar（弹出栏）原先用菜单栏平均颜色填充背景，不能呈现后方窗口内容的模糊效果。图标来自菜单栏截图，需保持清晰及原有黑白对比。

## Decision

仅在弹出栏背景复用 `VisualEffectView`，使用 `NSVisualEffectView`（原生视觉效果视图）的 `popover` 材质与 `behindWindow`（窗口后方混合）模式。窗口显式设为非不透明；原有圆角裁剪、阴影、边框和非全屏染色继续适用，染色放在图标下方。

材质明暗跟随菜单栏采样亮度，以配合不可重新着色的截图图标；无采样时跟随系统外观。开启“降低透明度”时以系统窗口底色替代材质。该选择独立于[设置窗口外观](2026-11-04-macos-settings-appearance.md)，不改变设置布局分区。

## Alternatives considered

- 对整个 SwiftUI（声明式界面框架）视图使用 `blur`（模糊）修饰器：会模糊图标，且不能采样窗口后方内容。
- 保留不透明平均底色再叠加材质：底色仍会遮住后方窗口，无法达到背景毛玻璃效果。
- 自行截图并做高斯滤镜：增加截图刷新和资源管理成本；原生材质已提供动态背景模糊及系统适配。

## Consequences

模糊强度由 macOS 管理，不提供固定高斯半径，也不引入私有滤镜接口或新设置。全屏场景同样使用原生模糊背景。图标截图与点击路径保持原有实现。

编译与打包检查不能证明背景合成效果；真实弹出栏还需在已授予辅助功能与屏幕录制权限的实例上检查，尤其是深色图标、全屏和降低透明度场景。
