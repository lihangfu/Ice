# Agent Note: Unified menu bar appearance

Status: implemented

## Problem

菜单栏外观同时维护静态、浅色和深色配置，并提供按住预览。用户希望移除独立的深浅色设置，避免同一套着色、阴影和边框重复配置。

## Decision

只保留统一配置，删除动态开关、两套编辑器和预览状态。旧动态配置在首次读取时选取当时系统外观对应的配置，随后写回静态配置，并编码 `isDynamic: false`，使旧版本读取时也使用同一套配置。旧静态配置、形状和内缩设置保持原值。

配置类型和持久化键继续使用 V2，旧键仅用于读取迁移；不为已经取消的模式保留运行时状态。设置窗口的原生深浅色适配继续由系统负责，与用户菜单栏自定义值分开。

## Alternatives considered

- 只隐藏深浅色编辑器：后台仍会切换两套不可编辑设置，不符合移除功能的要求。
- 总是迁移浅色或静态配置：可能让正在使用深色动态配置的用户立刻失去当前外观。
- 用覆盖文字和图标的半透明蒙版实现背景调节：不符合只改变背景的要求，不作为实现路径；此实验功能现已退役。

## Consequences

统一配置以后不再随系统主题切换。迁移会舍弃当时未激活的另一套动态配置，不能在新界面中恢复该分组；系统主题切换不会再改变着色、阴影或边框。

真实打包入口覆盖两种系统外观下的迁移、往返编码、旧静态与空配置、错误类型。`--validate-appearance` 渲染实际编辑器，不调用管理器初始化或保存用户偏好。

顶部菜单栏背景模糊已按用户要求[完整退役](2026-11-04-retire-menu-bar-background-blur.md)。它与独立的 [Ice Bar 磨玻璃背景](2026-11-04-ice-bar-backdrop-blur.md) 分开，后者仍保留。
