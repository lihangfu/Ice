# Agent Note: Settings surface colors

Status: implemented

## Problem

设置页用系统窗口颜色叠加透明色生成分组底色，侧栏使用系统材质，无法稳定呈现用户提供的三层浅色参考值。该决定细化[设置窗口外观](2026-11-04-macos-settings-appearance.md)的颜色来源。

## Decision

`SettingsPalette` 集中定义浅色外观的 sRGB（标准红绿蓝色彩空间）底色：侧栏为 227、229、231，内容背景为 239、241、243，分组为 235、237、239。浅色侧栏隐藏列表的系统滚动背景并绘制实色，分组取消额外透明叠色，避免材质与合成改变参考值。原生列表继续负责选择、键盘导航和行布局。

顶部静止时，右侧标题区与页面复用背景色；[设置窗口装配](../architecture/2026-11-05-settings-window-chrome.md)拥有永久透明的窗口外壳及右侧滚动材质，替代[滚动标题栏](2026-11-05-settings-scroll-titlebar.md)的窗口级切换。保留窗口标题语义、窗口按钮与侧栏分界，所有设置分页共享该行为；标题位置由[设置标题对齐](../bug-fix/2026-11-05-settings-title-alignment.md)统一处理。

深色侧栏继续使用原生背景，内容和分组保留原有系统窗口色及深色叠色。两种外观均跟随系统；文字、控件、选中态和分隔线保留系统语义颜色，增强对比度仍加强分组边框。共用设置样式的权限页同步采用页面底色，避免卡片与页面使用两套浅色来源。标准表单样式与 Ice Bar 不使用此配色。

## Alternatives considered

- 继续微调透明叠色：结果依赖系统底色，不能稳定匹配给定色值。
- 将浅色色值同时用于深色外观：会破坏系统主题适配与文字对比度。
- 全局替换系统颜色：影响其他窗口和原生控件，超出设置背景的范围。

## Consequences

浅色背景是参考截图的明确设计值，不代表 macOS 在各版本与显示配置下的系统颜色契约；未来更换配色应修改集中定义。真实窗口的六个分页、深浅外观与滚动取样由设置窗口装配的场景验证入口覆盖。单独指定高对比度 NSAppearance（原生外观对象）不会触发 SwiftUI 的增强对比度环境，因此快照不声称覆盖该系统辅助功能；增强对比度、不同显示器、系统版本和光照下的观感仍需人工验证。
