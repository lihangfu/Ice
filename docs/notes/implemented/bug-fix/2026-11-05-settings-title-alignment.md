# Agent Note: Settings title alignment

Status: implemented

## Problem

工具栏默认标题的左边距与设置卡片不一致；窗口变宽后，表单在限宽容器内居中，固定标题偏移也无法继续对齐。

## Decision

表单通过 SwiftUI（声明式界面框架）的 PreferenceKey（布局偏好键）报告卡片内容在详情区域中的实际左边缘。标题跟随该位置，包含限宽居中与滚动条占用空间的影响。[设置窗口装配](../architecture/2026-11-05-settings-window-chrome.md)将标题放入同一详情列的固定覆盖层，替代工具栏项目的尺寸与边距补偿。共享布局定义拥有 720 pt（逻辑点）内容宽度上限与 20 pt 水平留白。

窗口的导航标题继续提供当前分页名称，隐藏系统重复绘制的标题；macOS 15 及以上同时移除默认标题工具栏项目。标题保留标题辅助功能语义，窗口仍使用原生工具栏和窗口按钮。背景连续及分割线处理沿用[设置背景配色](../feature/2026-11-05-settings-surface-colors.md)。

## Alternatives considered

- 只增加固定的标题内边距：能修正窄窗口，无法适配表单限宽居中后的左边缘。
- 按窗口宽度估算并硬编码滚动条宽度：会重复系统实际布局，且短页面与滚动条显示偏好可能不同。
- 把标题移入可滚动表单：改变标题位置与滚动行为，超出对齐需求。

## Consequences

布局偏好仅在设置样式的表单中发出，由设置详情视图消费；标准表单沿用原样式。已有完整窗口截图覆盖六个分页的浅深切换，并补充 1100 与 1500 pt 宽窗口以检查限宽后的对齐。其他 macOS 版本仍需人工验证。
