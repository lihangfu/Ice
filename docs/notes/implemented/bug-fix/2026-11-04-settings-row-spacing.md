# Agent Note: Settings row spacing

Status: implemented

## Problem

[设置窗口外观](../feature/2026-11-04-macos-settings-appearance.md)使用原生侧栏，但把完整目标行高又设为行内容的最小高度，叠加系统行内边距后，中等尺寸的相邻选项约隔 36 pt（逻辑点）。用户提供的系统设置截图约为 28 pt。右侧组内相邻行约隔 43 pt，已接近参考图；差异主要在单行卡片上下留白与卡片之间的距离。

## Decision

侧栏内容以图标尺寸约束最小高度，由原生列表添加行内边距；小、中、大图标分别采用 16、20、26 pt，保留系统侧栏尺寸偏好和现有字号。图标与标题距离为 6 pt，对齐参考图中的文字起点。

设置表单与分组直接使用调用方的 `spacing`，移除设置样式额外施加的 16 pt 组间距和 14 pt 分组内边距下限。默认均为 10 pt；分隔线两侧间距和 22 pt 内容最小高度保持不变，使单行卡片约高 42 pt，与多行组内的视觉节奏一致。复杂编辑器和多行提示仍可按内容增高，显式传入的较大间距继续生效。

## Alternatives considered

- 缩小所有字号或统一降低组内行高：组内行距已接近参考图，缩小会降低可读性并挤压复杂控件。
- 固定每行的最终高度或以负边距抵消系统留白：会耦合系统内部布局，并限制较大侧栏尺寸与多行内容。
- 替换原生列表或整套表单：间距可在现有组件中修正，无需改变选择、键盘导航和控件行为。

## Consequences

变更只调整侧栏内容尺寸与设置样式曾额外增加的留白，共享组件的标准样式行为不变。已有外观验证入口扩展为渲染真实 `SettingsView` 和通用页，覆盖最小窗口宽度、三种侧栏尺寸及浅色和深色；快照供视觉检查，不将截图估算值当作所有 macOS 版本的固定系统契约。真实权限授权和菜单栏操作不属于该布局快照的覆盖范围。
