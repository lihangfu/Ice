# Agent Note: Ice Bar system appearance

Status: implemented

## Problem

按顶部菜单栏采样亮度选择弹出栏材质，会使浅色系统外观下的 Ice Bar 仍呈现深灰色。背景明暗应遵循系统外观，不应由壁纸或菜单栏颜色决定。

## Decision

移除 Ice Bar 的外观覆盖，让原生面板和 SwiftUI（声明式界面框架）内容继承应用的系统外观，并随外观切换更新。删除仅用于该判断的菜单栏颜色采样管理器及其定时器、通知订阅和环境注入。

本决定仅取代[背景模糊](../feature/2026-11-04-ice-bar-backdrop-blur.md)中的明暗选择策略；原生材质、降低透明度回退、染色、阴影与图标截图行为继续适用。

## Alternatives considered

- 保留亮度阈值或调整阈值：仍会使弹出栏外观受菜单栏颜色影响，不满足跟随系统的要求。
- 另行监听系统主题并手动设置外观：原生视图已有外观继承与更新机制，无需维护第二份主题状态。

## Consequences

外观验证入口使用真实 Ice Bar 宿主和面板，检查浅色、深色及切回浅色时材质的有效外观，并保存快照。验证只在独立进程内切换应用外观，不改变用户的系统偏好。

图标保留截图像素，不随材质重新着色。菜单栏图标颜色与系统外观不一致时，对比度仍需在已授权实例上目视检查；不能以此恢复亮度驱动的外观选择。
